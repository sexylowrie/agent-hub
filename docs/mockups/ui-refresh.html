视觉

  • 全部颜色走设计令牌（CSS 变量），浅色 / 深色两套只换变量；厂商色在两套主题下分别调过对比度。
  • iOS 风格：大标题 + 毛玻璃导航栏（滚动后出分隔线）、inset grouped 圆角卡片列表、分段控件。
  • 厂商用渐变头像块（C / Cx / Cu）代替左侧色条；头像右下角小圆点表示状态：运行中蓝色呼吸、待审批琥珀色。
  • 来源标签 GUI / CLI 用中性灰，Hub 用主题色，降低视觉噪音。

详情页

  • 用户消息是气泡；AI 回复不套气泡、全宽排版，支持轻量 Markdown（粗体、行内代码、代码块、列表），不加依赖，先转义再渲染。
  • 工具调用：按类型配图标（终端 / 文件 / 搜索），右侧状态：转圈 / 对勾 / 叉，点开看输入与输出。
  • 审批卡片：琥珀色描边 + 倒计时圆环，三个大按钮（拒绝 / 本会话允许 / 允许）。
  • 输入栏悬浮圆角，发送是圆形箭头；Hub 轮次进行中变成红色"停止"；不可发送时上方一行原因提示。上滑离开底部时出现"↓ 新消息"。

主题

  • 三档：跟随系统（默认）/ 浅色 / 深色；设置页选，列表导航栏也有一键切换。
  • 存 localStorage，页面加载前就设好（不闪白）；同步更新 theme-color，iOS 状态栏颜色跟着变。
  • 跟随系统时监听 prefers-color-scheme，系统切换即时生效。

交互细节

  • 按下反馈（轻微缩放 / 背景变深）；组折叠、箭头旋转带过渡；加载用骨架屏替代"加载中…"。
  • 发送失败、审批失败用顶部轻提示（toast），不占正文位置。
  • 分组规则、默认只展开一个组、新审批自动展开「待审批」保持不变。
